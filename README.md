# OOP_Lab7_Coffe — Serialization / Deserialization

Практична робота № 7 з дисципліни «Об'єктно-орієнтоване програмування».
Тема: **збереження і завантаження колекції об'єктів у файли \*.csv і \*.json**.

Виконала: Велигодська А.С., група 621п, ХАІ.

Предметна область – облік кавових напоїв. Клас предметної області – `Coffee`
(перелік `CoffeeType`), колекція – `List<Coffee>`.

## Структура рішення

| Проєкт | Файли | Призначення |
|---|---|---|
| `OOP_Lab7_Coffe` | `Coffee.cs`, `Program.cs` | Консольний застосунок (.NET 10): клас `Coffee`, перелік `CoffeeType`, конвертер дати для JSON, клас `Program` з методами роботи з колекцією, серіалізації/десеріалізації та меню |
| `OOP_Lab7_Coffe.Tests` | `CoffeeTests.cs`, `ProgramTests.cs`, `SerializationTests.cs`, `MSTestSettings.cs` | Модульні тести MSTest: тести з Lab-5 і Lab-6 та новий тест-клас `SerializationTests` |

## Зміни порівняно з Lab-6

- **CSV.** `SaveToFileCsv` записує заголовок `Code,Name,Type,Price,RoastDate,IsDecaf,VolumeMl`
  і по одному рядку `Coffee.ToString()` на об'єкт (роздільник – кома).
  `ReadFromFileCsv` читає файл поелементно через `Coffee.Parse`: коректні рядки
  стають об'єктами, «биті» (пропущені поля, невірні типи даних, значення поза діапазоном)
  пропускаються, а для кожного з них формується повідомлення з номером рядка і причиною.
- **JSON.** `SaveToFileJson` / `ReadFromFileJson` серіалізують і десеріалізують **всю колекцію
  цілком** (`System.Text.Json`, без додаткових NuGet-пакетів).
  Властивості перейменовано атрибутом `[JsonPropertyName]`, службові властивості
  (`Currency`, `TemperatureC`, `PricePer100Ml`) виключено атрибутом `[JsonIgnore]`.
  Десеріалізація йде через конструктор з атрибутом `[JsonConstructor]`, тому значення
  перевіряються так само, як під час створення об'єкта, а `Coffee.Counter` збільшується.
  Якщо файл пошкоджений, генерується `FormatException`, а лічильник повертається до попереднього значення.
- **Додавання до непорожньої колекції.** `AddLoadedCoffees` дописує зчитані об'єкти в кінець списку.
  Код замовлення має бути унікальним, тому об'єкт із кодом, який уже є у списку,
  отримує новий унікальний код (`GenerateUniqueCode`) – користувач бачить повідомлення.
  Об'єкти, що не вміщуються в `maxCount`, пропускаються.
- **Перевірка назви файлу.** `TryGetFilePath` додає розширення, якщо його не вказано,
  і відхиляє чуже розширення та недопустимі символи.
- Усі нові методи не використовують `Console`, тому покриті unit-тестами.

### Формат JSON

```json
[
  {
    "code": "AB1234",
    "title": "Ranok Blend",
    "kind": "Latte",
    "price_uah": 85.5,
    "roasted": "2024-03-15",
    "decaf": false,
    "volume_ml": 250
  }
]
```

## Меню програми

```
1 – Додати об'єкт
2 – Переглянути всі об'єкти (з можливістю сортування)
3 – Знайти об'єкт
4 – Продемонструвати поведінку
5 – Видалити об'єкт
6 – Продемонструвати static-методи
7 – Зберегти колекцію об'єктів у файлі   → 1 – *.csv, 2 – *.json
8 – Зчитати колекцію об'єктів з файлу    → 1 – *.csv, 2 – *.json
9 – Очистити колекцію об'єктів
0 – Вийти з програми
```

Формат рядка CSV (так само, як для введення рядком у п. 1):
`Код,Назва,Тип,Ціна,dd.MM.yyyy,Так/Ні,Об'єм`, наприклад
`AB1234,Ranok Blend,Latte,85.50,15.03.2024,Ні,250`.
